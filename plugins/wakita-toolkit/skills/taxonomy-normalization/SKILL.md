# 分类字段归一化流水线

## 何时触发

- 标注数据里的分类字段（纹样类型、应用场景、地域/民族、历史时期等）存在同义词、简称、
  异体字、括号说明、父子级共存
- 需要把原始标注词映射到元数据分类树的标准 code
- 需要批量识别「跨大类组合」和「体系外新分类候选」

## 输入 / 输出契约

**输入**

1. 元数据分类树（含 `label → code` 与父子关系）
2. 标注数据（JSON/CSV，至少含目标分类字段）
3. 同义词/映射规则表（NORM）

**输出**（每条记录三列）

| 列 | 内容 | 示例 |
|----|------|------|
| 分类映射 | 归一化后的标准名 | `缠枝纹` |
| 分类代码 | 元数据编码 | `1.2.3.1` |
| 分类新增 | 新分类/组合标记 | `花鸟纹样` / `组合纹` |

## 五步流水线

```
原始文本 → 分词（保护括号）→ 逐词解析（优先级）
→ 层级去重（只留最末子类）→ 跨类检测（2+ code → 组合纹）→ 输出
```

### 1. 分词

- 分隔符：`|` `，` `,` `、`
- **括号保护**：`（）`/`()` 内的逗号不作为分隔符
- 空格：短词（≤8 字符）之间的空格作为分隔符；含括号的长词内空格不分割

### 2. 逐词解析（按优先级）

```
1. 直接在 label→code 映射中 → 返回 code
2. 命中「花鸟」类关键词 → 标记新分类候选
3. 命中「组合」类关键词 → 标记组合纹
4. 命中 NORM 同义词表 → 转为标准名(code)
5. 剥括号后递归解析 → 处理「XX纹（说明）」
6. 含工艺关键词 → 归「其他」
7. 含场景关键词 → 归「其他」
8. 均不命中 → 留空并保留原文，交人工复核
```

**禁止**：不命中时凭语义猜一个 code 写进去。留空 + 保留原文是唯一安全默认。

### 3. 层级去重

父子级同时命中时只保留最末级子类：

```python
dedup_codes(["1.2", "1.2.3.1"]) -> ["1.2.3.1"]   # 去父留子
dedup_codes(["1.1", "1.3"])     -> ["1.1", "1.3"]  # 不同类保留
```

### 4. 跨类检测

解析后仍有 2 个及以上独立 code 且非父子关系 → 标记「组合纹」，
同时保留原始 code 列表供人工判断。

### 5. 输出与复核

- 按记录输出三列，附「未命中明细」清单
- 新分类候选单独汇总，按出现频次排序
- 抽样人工复核：高频词、未命中词、新候选词各抽一批

## NORM 映射表（核心资产）

同义词/简写/异体字的映射规则集，决定清洗质量。最少覆盖：

- 简称补全：`几何纹 → 几何纹样`
- 异体归一：`涡纹 → 漩涡纹`
- 同义归并：`凤鸟纹 → 凤纹`
- 复合词取主词：`忍冬卷草纹 → 忍冬纹`
- 整句映射：`双龙戏珠纹（龙纹的一种，对称式复合纹样）→ 龙纹`

辅助函数：

```python
def normalize_quotes(s):
    return s.replace("\u201c", '"').replace("\u201d", '"')

def strip_br(s):
    return re.sub(r"[（(][^）)]*[）)]", "", s).strip()
```

## 验证清单

- [ ] 分类树节点数与 `label→code` 映射数一致，无空 code
- [ ] 分词不破坏括号内逗号
- [ ] 层级去重后无父子共存
- [ ] 跨类记录全部进入人工复核清单
- [ ] 未命中记录保留原文，未凭空造 code
- [ ] 输出条数 = 输入条数（无静默丢行）
- [ ] 重复运行结果一致（幂等）

## 复用到其他维度

把同一流水线用于应用场景/地域/民族/历史时期时，需要替换：

1. `label→code` 数据源指向该维度分类树
2. NORM 映射表按该维度重建
3. 新分类候选规则按该维度调整
4. 工艺/场景关键词规则通常不适用，需删除或重写

## 反模式

- ❌ 按「看起来像」给未知词分配 code
- ❌ 父子级都保留，导致统计重复计数
- ❌ 直接按逗号 split，破坏 `（A，B）` 这类括号说明
- ❌ 只输出清洗结果，不输出未命中/新增清单，问题被静默吞掉
